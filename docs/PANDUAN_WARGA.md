# Panduan Warga - Cara Melapor via WhatsApp

Dokumen ini ditujukan untuk **Warga Desa** yang ingin menyampaikan pengaduan atau keluhan melalui layanan WhatsApp Helpdesk Desa.

## Persyaratan

- Memiliki aplikasi WhatsApp di HP.
- Menyimpan nomor WhatsApp Helpdesk Desa ke kontak HP Anda. Nomor akan diinformasikan oleh perangkat desa.

## Cara Melapor

### Langkah 1: Mulai Percakapan

Buka WhatsApp, cari kontak **Helpdesk Desa**, lalu ketik dan kirim pesan:

```
LAPOR
```

Bot akan membalas dan meminta Anda menuliskan deskripsi pengaduan.

### Langkah 2: Tulis Deskripsi Masalah

Tuliskan keluhan atau masalah yang ingin dilaporkan secara jelas dan lengkap. Minimal 10 karakter.

Contoh:

```
Jalan di RT 03 RW 02 rusak parah dan berlubang besar, sudah menyebabkan kecelakaan motor.
```

### Langkah 3: Kirim Foto Bukti

Setelah deskripsi diterima, bot akan meminta Anda mengirimkan foto bukti.

- **Kirim foto:** Ambil foto masalah yang terjadi, lalu kirimkan seperti biasa melalui WhatsApp.
- **Tidak ada foto:** Ketik `LEWATI` untuk melewati langkah ini.

### Langkah 4: Kirim Lokasi Kejadian

Bot akan meminta Anda mengirimkan titik lokasi kejadian. Caranya:

1. Tekan ikon **lampiran (+)** atau ikon **klip** di kolom chat WhatsApp.
2. Pilih menu **Lokasi**.
3. Pilih **Kirim Lokasi Anda Saat Ini** atau geser pin ke titik yang tepat.
4. Tekan tombol **Kirim**.

Jika tidak ingin mengirim lokasi, ketik `LEWATI`.

### Langkah 5: Laporan Terkirim

Setelah semua langkah selesai, bot akan mengirimkan konfirmasi berisi ringkasan laporan Anda:

```
PENGADUAN BERHASIL DIKIRIM!

No. Laporan: #7
Deskripsi: Jalan di RT 03 RW 02 rusak parah...
Foto: Terlampir
Lokasi: -7.7956,110.3695
Status: Menunggu

Terima kasih telah melapor.
Petugas akan menindaklanjuti pengaduan Anda.
```

## Perintah yang Tersedia

| Perintah | Fungsi |
|----------|--------|
| `LAPOR` atau `1` | Memulai proses pelaporan pengaduan baru |
| `MENU` | Menampilkan menu utama |
| `LEWATI` | Melewati langkah foto atau lokasi |
| `BATAL` | Membatalkan proses pelaporan yang sedang berjalan |

## Catatan Penting

- Satu nomor WhatsApp dapat membuat **banyak laporan**.
- Perintah tidak harus huruf besar. Anda boleh mengetik `lapor`, `Lapor`, atau `LAPOR`.
- Jika terjadi kesalahan atau bot tidak merespons, ketik `MENU` untuk memulai ulang.
- Laporan Anda akan ditindaklanjuti oleh petugas desa. Pantau perkembangan melalui perangkat desa setempat.
